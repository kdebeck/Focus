# Focus

A nature-inspired weekly planning app.

- Home: focus of the week, suggested focus, priorities, and weekly overview.
- Habits: add or delete habits anytime. Habits persist into future weeks until deleted; checkmarks are date-specific.
- Days: add daily items, mark them complete, and flag any item as a Priority. Priority items automatically appear on Home.
- Notes: free-form miscellaneous notes.

All data is stored locally in the browser on the device.
