# Focus — combined home screen

Upload all files in this folder to the ROOT of your existing Focus GitHub Pages repository (replace index.html, manifest.json, and icons only if necessary). Keep the Focus URL the same to preserve existing Focus localStorage data. The original Focus icon files are included.

The home screen includes: weekly focus, repeating daily essentials and the optional suggestion at the end of that section, original Home Reset weekday cleaning (Sunday free), dog-hair and survival routines, carryover priorities, habits, days, and notes. All appear on one scrolling page.

**Before replacing**: Save a copy of your old files. Data is stored in the browser on each device, not in GitHub. If you host this on a new URL instead of the original Focus URL, existing priorities/habits won't automatically follow. Original Home Reset data is separate; only same-origin checkmarks for the current day can be recovered automatically.

After uploading: refresh the Focus website in Safari, possibly close/reopen the Home Screen app. The service worker should update on connection.
